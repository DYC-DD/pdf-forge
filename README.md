# [PDF Forge](https://dyc-dd.github.io/pdf-forge/)

合併、拆分、壓縮 PDF，或將頁面轉成 JPG／PNG 圖片，打開瀏覽器就能輕鬆搞定。免安裝、免上傳，讓每份檔案安心留在你的裝置。

## 功能與用法

| 工具                                                     | 操作方式                                                                                                                          | 下載結果                                         |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| [合併 PDF](https://dyc-dd.github.io/pdf-forge/merge/)    | 加入至少兩份 PDF，拖曳檔案列調整順序；可預覽原檔與合併結果，並自訂輸出檔名。                                                      | 一份 PDF                                         |
| [拆分 PDF](https://dyc-dd.github.io/pdf-forge/split/)    | 加入一份 PDF，點選縮圖或輸入頁碼範圍（例如 `1-3, 5, 8`），將選取的頁面加入輸出清單；也可選擇「每頁一檔」。                        | 一份結果下載 PDF；多份結果下載 ZIP               |
| [壓縮 PDF](https://dyc-dd.github.io/pdf-forge/compress/) | 一次加入一份 PDF 或 JPG／PNG，自動辨識壓縮模式；選擇強度，完成後比較大小並預覽結果。                                              | 結果較小時可下載 PDF 或原格式圖片                |
| [轉換 PDF](https://dyc-dd.github.io/pdf-forge/convert/)  | 自動辨識 PDF 或 JPG／PNG。PDF 可選頁轉 JPG／PNG；圖片可排序、旋轉、預覽並轉 PDF、JPG、PNG、SVG（嵌入圖片）或 WEBP，保留原始像素。 | 圖片合成一份 PDF；單張直接下載圖片、多張打包 ZIP |
| 05 PDF2docx（開發預覽，`/pdf2docx/`）                    | 加入 PDF、選頁並分析，在結構預覽核對文字、段落與表格，再下載可編輯文件；支援瀏覽器本機繁中／英文 OCR。                            | 一份可編輯 DOCX                                  |

## 本機執行

建議使用 Node.js 22.13 以上及 npm。  
安裝依賴後啟動開發伺服器：

```bash
npm ci
npm run dev
```

其他常用指令：

```bash
npm test              # 執行 Vitest 測試
npm run build         # TypeScript 檢查並產生 dist/
npm run preview       # 預覽正式建置
npm run format        # 使用 Prettier 格式化
npm run format:check  # 檢查格式
```

## 各模式說明

### 合併 PDF

- **單檔上限**：64 MB、600 頁。
- **合併上限**：30 份 PDF，總計 160 MB、900 頁。

### 拆分 PDF

- **匯入上限**：一份 PDF，最多 64 MB、600 頁。
- **輸出上限**：每次 100 份 PDF、累計 600 頁，包含重複選取的頁面。
- 「每頁一檔」最多處理 100 頁；超過時請改用自訂範圍分批輸出。

### 壓縮 PDF

一次處理一個檔案，提供低、中、高三種強度；結果沒有更小時保留原檔。背景處理超過 2 分鐘會停止，可改用低壓縮或拆分 PDF 後重試。

- **PDF 壓縮**
  - **匯入上限**：64 MB、600 頁。
  - **壓縮效果**：保留文字與向量內容；超出圖片處理限制時保留原圖。

- **圖片壓縮**
  - **匯入上限**：一張 JPG／PNG，最多 64 MB、4,000 萬像素，單邊不超過 16,384 像素。
  - **強度差異**：低壓縮清理附加資料；中壓縮維持尺寸；高壓縮將最長邊限制為 1,920 像素，不放大較小圖片。
  - **輸出特性**：維持原格式，PNG 保留透明背景；不支援動態 PNG。

### 轉換 PDF

- **PDF 轉圖片**
  - **匯入上限**：一份 PDF，最多 64 MB、600 頁。
  - **輸出上限**：每次 100 張、總計 128 MB；單張最多 1,600 萬像素，單邊不超過 8,192 像素。
  - **轉換效果**：保留頁面外觀，文字無法再選取；超過張數或總大小上限時請分批選頁。

- **圖片轉換**
  - **匯入上限**：100 張 JPG／PNG，單張 64 MB、總計 128 MB；單張最多 4,000 萬像素，單邊不超過 16,384 像素。
  - **輸出上限**：總計 128 MB，保留原始解析度，超過上限時請分批處理或改用其他格式。
  - **使用提醒**：PDF 與圖片需分開加入，不支援動態 PNG；背景處理超過 2 分鐘會停止。

    | 輸出格式 | 主要特性                                       |
    | -------- | ---------------------------------------------- |
    | PDF      | 一張圖片一頁，依排序合成一份文件。             |
    | JPG      | 透明區域補白，屬有損格式。                     |
    | PNG      | 無損輸出，保留透明背景與 8／16 位元色彩。      |
    | SVG      | 嵌入原始圖片，並非向量化。                     |
    | WEBP     | 無損輸出，保留透明背景；單邊最多 16,383 像素。 |

### PDF2docx（獨立開發預覽）

- **匯入上限**：一份 PDF，最多 32 MB、600 頁；每次分析最多 50 頁，其中 OCR 最多 10 頁。
- **輸出方式**：自動區分文字、表格、水平線與圖片；正文使用原生段落，支援清單、簡單雙欄、有框線表格、合併儲存格及底色，保留大型照片、向量裝飾、圖章與可判定的浮水印，支援基本分數公式及重複頁尾，不以逐行文字方塊輸出。
- **本機辨識**：OCR 程式、WASM 與語言模型由本站下載，文件內容不上傳。自動模式優先讀取原文字層，也可選擇整頁重新辨識。
- **品質界線**：尚未保證所有 PDF 的內容與排版精準；字型替代、掃描辨識與複雜內容需核對。直排、複雜公式、無框線表格及密集掃描圖文結構仍在開發；部分密集文件仍可能增加分頁。
- 05 與 04 分開開發，詳細進度與驗證方式見 [PDF2docx 開發紀錄](./docs/PDF2DOCX.md)。

## 注意事項

> [!IMPORTANT]
>
> - 合併、拆分、壓縮、圖片轉換與 PDF2docx 都在你的瀏覽器中完成。
> - 原始 PDF 和產生的結果不會上傳雲端或傳送至伺服器。
> - 重新整理或關閉頁面後，處理狀態不會保留；請先下載並保存結果。
