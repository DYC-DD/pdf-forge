# [PDF Forge](https://dyc-dd.github.io/pdf-forge/)

合併、拆分、壓縮 PDF，或將頁面轉成 JPG／PNG 圖片，打開瀏覽器就能輕鬆搞定。免安裝、免上傳，讓每份檔案安心留在你的裝置。

## 功能與用法

| 工具                                                     | 操作方式                                                                                                                  | 下載結果                           |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| [合併 PDF](https://dyc-dd.github.io/pdf-forge/merge/)    | 加入至少兩份 PDF，拖曳檔案列調整順序；可預覽原檔與合併結果，並自訂輸出檔名。                                              | 一份 PDF                           |
| [拆分 PDF](https://dyc-dd.github.io/pdf-forge/split/)    | 加入一份 PDF，點選縮圖或輸入頁碼範圍（例如 `1-3, 5, 8`），將選取的頁面加入輸出清單；也可選擇「每頁一檔」。                | 一份結果下載 PDF；多份結果下載 ZIP |
| [壓縮 PDF](https://dyc-dd.github.io/pdf-forge/compress/) | 加入一份 PDF，選擇壓縮強度，完成後比較大小並預覽結果。                                                                    | 結果較小時可下載 PDF               |
| [轉換 PDF](https://dyc-dd.github.io/pdf-forge/convert/)  | 加入一份 PDF，點選縮圖或輸入頁碼，選擇 JPG／PNG 及自訂輸出檔名；固定以 300 DPI 輸出，JPG 使用最高畫質，PNG 使用無損格式。 | 一張下載 JPG／PNG；多張下載 ZIP    |

## 本機執行

建議使用 Node.js 22.13 以上及 npm。  
安裝依賴後啟動開發伺服器：

```bash
npm ci
npm run dev
```

其他常用指令：

```bash
npm test              # 執行 Vitest 測試
npm run build         # TypeScript 檢查並產生 dist/
npm run preview       # 預覽正式建置
npm run format        # 使用 Prettier 格式化
npm run format:check  # 檢查格式
```

## 注意事項

> [!IMPORTANT]
>
> - 合併、拆分、壓縮與圖片轉換都在你的瀏覽器中完成。
> - 原始 PDF 和產生的結果不會上傳雲端或傳送至伺服器。
> - 重新整理或關閉頁面後，處理狀態不會保留；請先下載並保存結果。

為減少瀏覽器處理大型文件時的資源消耗，各工具有以下限制：

- 單檔最多 64 MB、600 頁。
- 合併最多 30 份，總計最多 160 MB、900 頁。
- 拆分每次最多輸出 100 份，累計複製最多 600 頁。
- 圖片轉換每次最多輸出 100 張、圖片總大小最多 128 MB，超過時可分批選取頁面；單張最多 1,600 萬像素、任一邊不超過 8,192 像素，超過單頁尺寸上限時會提示錯誤。
- 轉換圖片保留頁面外觀、方向與白色背景；輸出解析度依 PDF 頁面尺寸換算為像素，文字轉成圖片後無法選取。多張圖片依原始頁碼命名，打包為 ZIP。
- 壓縮會在介面及 Worker 檢查檔案大小與頁數；超過 2 分鐘會終止 Worker，可拆分檔案或改用低壓縮後重試。
- 圖片壓縮只處理單張最多 1,600 萬像素、任一邊不超過 8,192 像素的圖片；所有壓縮候選共用累計 6,400 萬像素的處理預算。JPEG 會先核對檔頭與 PDF 宣告的尺寸，再進行解碼。
- 超過圖片限制或預算的圖片保留原始資料；不適合整份圖片最佳化時，改用可處理的 JPEG 或只壓縮 PDF 結構。壓縮頁面的縮圖與預覽會略過超過 1,600 萬像素的圖片，輸出 PDF 的原始圖片仍會保留。
- 壓縮候選逐份驗證，只保留結構壓縮基底及目前最小的有效結果；單份候選或圖片重編碼暫存 PDF 超過 128 MB 時不再採用，處理結束會清除暫存檔。這是輸出大小檢查，並非瀏覽器記憶體的硬上限。
- 處理中可以取消。
- 符合上述限制的文件，仍可能因裝置記憶體不足而無法完成處理。
