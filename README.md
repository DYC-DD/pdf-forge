# [PDF Forge](https://dyc-dd.github.io/pdf-forge/)

合併、拆分、壓縮 PDF，或將頁面轉成 JPG／PNG 圖片，打開瀏覽器就能輕鬆搞定。免安裝、免上傳，讓每份檔案安心留在你的裝置。

## 功能與用法

| 工具                                                     | 操作方式                                                                                                                          | 下載結果                                         |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| [合併 PDF](https://dyc-dd.github.io/pdf-forge/merge/)    | 加入至少兩份 PDF，拖曳檔案列調整順序；可預覽原檔與合併結果，並自訂輸出檔名。                                                      | 一份 PDF                                         |
| [拆分 PDF](https://dyc-dd.github.io/pdf-forge/split/)    | 加入一份 PDF，點選縮圖或輸入頁碼範圍（例如 `1-3, 5, 8`），將選取的頁面加入輸出清單；也可選擇「每頁一檔」。                        | 一份結果下載 PDF；多份結果下載 ZIP               |
| [壓縮 PDF](https://dyc-dd.github.io/pdf-forge/compress/) | 加入一份 PDF，選擇壓縮強度，完成後比較大小並預覽結果。                                                                            | 結果較小時可下載 PDF                             |
| [轉換 PDF](https://dyc-dd.github.io/pdf-forge/convert/)  | 自動辨識 PDF 或 JPG／PNG。PDF 可選頁轉 JPG／PNG；圖片可排序、旋轉、預覽並轉 PDF、JPG、PNG、SVG（嵌入圖片）或 WEBP，保留原始像素。 | 圖片合成一份 PDF；單張直接下載圖片、多張打包 ZIP |

## 本機執行

建議使用 Node.js 22.13 以上及 npm。  
安裝依賴後啟動開發伺服器：

```bash
npm ci
npm run dev
```

其他常用指令：

```bash
npm test              # 執行 Vitest 測試
npm run build         # TypeScript 檢查並產生 dist/
npm run preview       # 預覽正式建置
npm run format        # 使用 Prettier 格式化
npm run format:check  # 檢查格式
```

## 注意事項

> [!IMPORTANT]
>
> - 合併、拆分、壓縮與圖片轉換都在你的瀏覽器中完成。
> - 原始 PDF 和產生的結果不會上傳雲端或傳送至伺服器。
> - 重新整理或關閉頁面後，處理狀態不會保留；請先下載並保存結果。

### 處理上限

為減少瀏覽器處理大型文件時的資源消耗，各工具有以下限制：

| 工具或項目 | 數量與檔案大小                                            | 頁數或圖片尺寸                                  |
| ---------- | --------------------------------------------------------- | ----------------------------------------------- |
| PDF 單檔   | 最多 64 MB                                                | 最多 600 頁                                     |
| 合併 PDF   | 最多 30 份，總計 160 MB                                   | 總計最多 900 頁                                 |
| 拆分 PDF   | 每次最多輸出 100 份                                       | 累計複製最多 600 頁                             |
| PDF 轉圖片 | 每次最多輸出 100 張，圖片總大小 128 MB                    | 單張最多 1,600 萬像素，任一邊不超過 8,192 像素  |
| 圖片模式   | 最多匯入 100 張，單張 64 MB、總計 128 MB；輸出上限 128 MB | 單張最多 4,000 萬像素，任一邊不超過 16,384 像素 |

處理中可以取消。即使符合上述限制，仍可能因裝置記憶體不足而無法完成處理。

### PDF 轉圖片

- 保留頁面外觀、方向與白色背景；輸出解析度依 PDF 頁面尺寸換算為像素，文字轉成圖片後無法選取。
- 多張圖片依原始頁碼命名，打包為 ZIP。
- 超過輸出張數或總大小上限時，可分批選取頁面；超過單頁尺寸上限時會提示錯誤。

### 圖片轉換

- 支援 JPG／JPEG／PNG 匯入，圖片與 PDF 需分開加入。靜態轉換不支援動態 PNG，以免遺失動畫影格。
- 正式輸出保留原始解析度，不降採樣或放大；旋轉只交換寬高或重排像素。預覽縮圖與正式輸出分開，超出處理上限時會提示分批或改用其他格式，不自動縮小圖片。
- 多張圖片依排序使用流水號命名，避免重名覆蓋；支援轉換與 ZIP 進度、圖片預覽及合成 PDF 預覽。

**各格式的輸出方式**

- **PDF**：一張圖片一頁，頁面依圖片比例建立，實體尺寸以 300 DPI 換算；EXIF 方向與手動旋轉套用在頁面上。JPEG 直接嵌入原始資料；PNG 保留 8／16 位元色彩與透明度，支援 ICC 色彩描述檔及 PNG gamma／色度資訊。
- **JPG**：以品質 100、4:4:4 完整色彩取樣編碼，透明區域補白；重新編碼後仍屬有損格式。
- **PNG**：無損輸出，旋轉保留原有 8／16 位元資料與透明背景。
- **SVG**：嵌入完整圖片，以變形處理方向與旋轉，保留原始圖片資料與色彩描述檔，並非向量化。
- **WEBP**：使用無損編碼，保留透明像素的 RGB 資料；任一邊最多 16,383 像素，超出時會提示改選其他格式。

JPG／PNG 輸出若與來源格式相同，且不需方向調整，會直接保留原始檔案。

**色彩與描述檔**

- JPG／WEBP 使用 8 位元色彩，16 位元來源會按完整數值範圍換算。
- RGB ICC 描述檔會沿用至 PNG、JPG、WEBP、PDF。
- 灰階 ICC 描述檔會沿用至 PNG、JPG、PDF；灰階圖片轉 WEBP 或處理 CMYK 來源時，由瀏覽器轉為 sRGB。

**執行方式**

圖片編碼器隨網站提供並按需載入，不會上傳圖片。支援 Worker 的瀏覽器會在背景處理，超過 2 分鐘終止；較舊的瀏覽器使用主執行緒處理。

### PDF 壓縮

- **檔案檢查與逾時**：介面及 Worker 都會檢查檔案大小與頁數。超過 2 分鐘會終止 Worker，可拆分檔案或改用低壓縮後重試。
- **圖片處理上限**：只處理單張最多 1,600 萬像素、任一邊不超過 8,192 像素的圖片；所有壓縮候選共用累計 6,400 萬像素的處理預算。JPEG 解碼前會先核對檔頭與 PDF 宣告的尺寸。
- **超出限制的處理**：超過圖片限制或預算時保留原始圖片；不適合整份圖片最佳化時，改用可處理的 JPEG 或只壓縮 PDF 結構。
- **縮圖與預覽**：略過超過 1,600 萬像素的圖片，輸出 PDF 仍保留原始圖片。
- **候選與暫存檔**：逐份驗證壓縮候選，只保留結構壓縮基底及目前最小的有效結果。單份候選或圖片重編碼暫存 PDF 超過 128 MB 時不再採用，處理結束後清除暫存檔。此限制用於檢查輸出大小，並非瀏覽器記憶體的硬上限。
