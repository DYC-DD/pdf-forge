# CHANGELOG

This changelog follows the [Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/) format to track version updates.

## [Unreleased]

### Added

- 新增獨立「05／PDF2docx」開發預覽與 `/pdf2docx/` 入口，維持 04 既有轉換流程；提供頁碼選取、原稿預覽、結構分析、逐頁診斷及可編輯 DOCX 下載。
- PDF2docx 初版重建原生段落、清單、簡單雙欄、有框線表格與合併儲存格，保留獨立圖片；提供本機繁中／英文 OCR、Worker 取消與逾時、文字覆蓋檢查，辨識程式及模型均由本站提供。
- PDF2docx 單檔上限 32 MB、每次分析 50 頁、OCR 10 頁；標示尚未完整支援的排版與內容，新增開發紀錄、實際 PDF／OOXML 測試及 OCR／Worker 生命週期測試。
- PDF2docx 新增只有橫線的數字表格辨識，在表頭與底線之間有至少三列完整對齊數字時，重建為保留橫線、無垂直框線的可編輯表格。
- 新增四份公開 PDF、共 11 頁的回歸案例清單、SHA-256 驗證下載與獨立測試指令，補齊分頁、表格及文字排版測試；提供 Windows Word 文件開啟、PDF 輸出與實際頁數比對腳本。

### Changed

- 以全部 9 份範例、65 頁持續驗證 PDF2docx：改為保留實際紙張座標、修正厚填色網格及跨欄文字歸屬、推估儲存格內距，新增基本可編輯分數及原生重複頁尾。繁中 OCR 優先使用繁中模型，英文主導頁面才重試英文；保留可判定的掃描圖形。
- 修正大型照片被排除、舊範本文字被誤讀及圖片白底遮住裝飾／頁尾；複雜圖像依繪製順序合成，正文保持可編輯，照片圖層以 JPEG 降低記憶體與檔案量。
- PDF2docx 依裝置可用字型量測中西文字寬，保留字級校準儲存格及 OCR 原稿行；修正重疊字框、細小清單標記、定位點空白及頁尾多餘行距。密集橫向繁中正文新增保守的本機 OCR 重試，涵蓋同一行被切成短片段的情況；匿名掃描案例恢復全部 28 個行首標記。掃描合約回到 25 頁、橫向清冊回到 6 頁；保留 Word／LibreOffice 密集表格分頁差異及尚待逐字驗收的紀錄。

- PDF2docx 新增物件歸屬分類，區分正文、表格、底線、水平分隔線、圖片、浮水印及掃描頁碼；保留原生字色、表格底色／框線及圖章透明背景，獨立地圖頁可直接保留為圖片。
- 改善掃描表格線預處理、誤判直排的清單標記、字級估算、封面留白與頁尾；修正小數被當成清單、靠右數字重複縮排及表格框線／留白累積造成的多餘分頁。新增匿名 PDF／OOXML 與物件分類回歸測試。

- 「05／PDF2docx」自動辨識紙張、方向與邊界，優先匹配 A4／A3／A5／Letter 與窄／標準邊界；綜合同尺寸頁面的正文位置推估，保留明確的自訂尺寸與邊界。界面僅顯示辨識結果，不需手動選擇；依可用區域調整欄寬、表格和圖片，文字保留字級並自然換行。
- 改善 PDF2docx 短雙欄與 OCR 區塊／段落分界，並排圖片改用原生無框線表格，簡單側邊照片使用原生圖文環繞；圖片裁切範圍限制於頁內，合併重疊分片與相接圖片磚，避免圖片拆散或重複。
- 「05／PDF2docx」沿用轉換工具的 MUI 深色選單與欄位樣式，分頁選項改用 MUI Checkbox，並使用提供的 DOCX 與 zoom-scan 分析圖示。
- PDF2docx 預設勾選「保留原稿分頁」，保留原生正文換行與來源頁面邊界；取消勾選可讓段落跨頁接續，文字仍可編輯，Word 會依可用字型及編輯內容重新排版。
- 改善 PDF2docx 替代字型字寬校準與清單懸掛／右縮排；保留原稿分頁時停用可能將整段推到下一頁的孤行及標題接續設定，清單續行交由 Word 換行，減少重複換行與多餘分頁。

### Fixed

- 修正 PDF2docx 分欄切回通欄時重複累加上方留白，並改善置中短標題下方的雙欄辨識，避免大面積表格的表頭被誤拆為雙欄正文。
- 修正密集表格的相近雙框線位置判定，避免端點微小間隙造成錯誤的非矩形合併儲存格。
- 保留 PDF 明確的詞間空白及上／下標基線位移，並在結構預覽顯示上／下標；補齊 Nimbus／Computer Modern 字型對應。
- 修正頁尾頁碼欄位辨識，只將目前頁碼轉為動態欄位，保留來源總頁數文字，並支援頁碼數字跨不同文字樣式的情況。
- DOCX 段落定位點改為排序、去重並限制最多 64 個，修正密集定位點造成 Word 無法開啟文件的問題。
- 修正 Windows 測試中的檔案路徑與 Worker URL，避免磁碟代號路徑錯誤導致 WASM、CMap 等 PDF 資源載入失敗。

## [1.1.0] - 2026-10-09

### Added

- 壓縮工具新增 JPG／PNG 圖片壓縮，依檔案內容自動辨識 PDF 或圖片；一次只接受一個檔案，清除後恢復 PDF 模式。提供三種強度、原圖與結果預覽、大小比較、原格式下載及 Worker 取消／逾時處理；PNG 保留透明度與 16 位元資料。
- 轉換工具自動辨識 PDF 或 JPG／PNG 圖片；圖片模式支援 PDF、JPG、PNG、SVG（嵌入圖片）及 WEBP，單張直接下載、多張圖片打包 ZIP，PDF 則依圖片順序合成一份。
- 圖片模式沿用列表與各尺寸網格，支援拖曳與鍵盤排序、90° 旋轉、圖片放大預覽及合成 PDF 預覽；保留原始像素，PDF 直接嵌入圖片並處理 EXIF 方向，PNG 保留透明度，JPG 透明區域補白。
- 圖片轉換提供 Worker 處理、取消與進度顯示；每次最多 100 張、單張 64 MB、總計 128 MB，單張最多 4,000 萬像素／單邊 16,384 像素，輸出上限 128 MB。
- 新增「04／轉換 PDF」與獨立 `/convert/` 網址，支援 PDF 轉 JPG／PNG；可透過縮圖或頁碼選取頁面及設定輸出檔名，固定以 300 DPI、JPG 最高畫質或 PNG 無損格式輸出，單張直接下載圖片、多張打包 ZIP。
- 轉換沿用列表、大網格、中網格與小網格、頁面預覽及本機處理流程；提供轉換與 ZIP 進度、取消操作及輸出頁數、像素與大小限制。

### Changed

- 圖片模式固定保留原始解析度與各格式最佳品質：JPG 使用品質 100／4:4:4 色彩取樣，WEBP 改用明確無損編碼；PNG 旋轉與 PDF 嵌入保留 16 位元樣本、透明度及色彩描述檔，SVG 以變形保留完整原圖。
- 圖片正式輸出改用原始資料與固定編碼器，預覽縮圖獨立處理；補上 WEBP 格式尺寸限制、ICC 通道檢查及動態 PNG 提示，超出限制時不自動降低解析度。
- 「04／轉換 PDF」初始上傳區可同時接受 PDF 或圖片，混合來源時提示分開加入；清空後恢復自動辨識，未加入檔案時顯示中性的等待狀態。
- 轉換的 JPG／PNG 格式切換改用 MUI 下拉選單，沿用深色欄位與選單樣式，並在選項中加入格式適用說明。
- 四個工具共用同一份顯示偏好，在任一工具切換列表或網格尺寸後，其他工具及重新載入頁面皆沿用該設定；未設定時統一使用列表。
- 壓縮模式改用共用檔案卡片，在清除按鈕右側加入列表、大網格、中網格與小網格切換；縮圖依頁面實際比例顯示，支援點選縮圖或眼睛按鈕預覽。
- 合併、拆分與轉換的網格顯示擴充為大、中、小三種尺寸，寬版每排分別顯示 3、4、5 張；小網格使用提供的 grid-5x5.svg 圖示，工作區較窄時自動減少欄數。
- 工具選擇區調整為桌面四欄、平板兩欄與手機單欄，並使用提供的 photo.svg 作為轉換工具圖示。
- 拆分與轉換共用頁面縮圖元件；輸出檔名欄位支援 PDF、JPG、PNG 與 ZIP 副檔名。

### Fixed

- PDF 放大預覽逐頁限制畫布為最多 400 萬像素、單邊 4,096 像素，納入螢幕像素密度與像素取整；特殊尺寸頁面自動降低預覽解析度，維持顯示尺寸、比例與完整內容，不影響下載輸出。

## [1.0.2] - 2026-10-07

### Added

- 合併與拆分新增列表、大網格及小網格三種瀏覽方式，並分別記住各工具的顯示偏好；大網格每排 3 張、小網格每排 4 張，工作區較窄時自動減少欄數。
- 壓縮補上單檔 64 MB、600 頁限制、2 分鐘逾時終止、圖片尺寸與累計像素預算，並限制預覽圖片解碼；候選結果改為逐份驗證，釋放未採用結果與暫存檔，保留可用的結構壓縮結果。
- 合併與拆分支援移植 AcroForm 欄位、欄位值、控制項及原始外觀；合併時自動處理同名欄位群組與字型資源，拆分時只保留所選頁面的控制項及對應欄位。

### Changed

- 統一合併檔案與拆分頁面的列表、網格卡片樣式，調整縮圖、文字資訊及不同螢幕尺寸的排版。
- 瀏覽方式切換採用膠囊按鈕，放在清除按鈕右側，僅在有檔案時顯示；切換時加入透明度、縮放與模糊動畫，並配合減少動態效果偏好。
- 合併檔案的操作按鈕在列表與網格中統一依「拖移、預覽、移除」排列，網格操作列移至卡片上方。
- 合併模式的檔案縮圖與文字區改為可直接拖曳排序，預覽改由眼睛按鈕開啟；列表、大網格及小網格的操作一致。
- 拆分的列表與網格統一使用 MUI Checkbox，選取框放在預覽按鈕右側，網格操作列位於卡片上方；選取框圖示與預覽圖示皆為 17px。
- 拆分頁面的選取狀態與頁碼標題同排顯示，頁碼靠左、狀態靠最右側，已加入的群組數量保留在下一行。
- 拆分的模式切換、快速選取頁碼與套用按鈕整合為同一排工具列，高度統一為 36px，套用按鈕懸停時維持對齊；選取計數、全選與清除操作靠右並垂直置中，空間不足時自動換行。
- 合併與拆分的縮圖依頁面實際比例及旋轉方向顯示橫式或直式；合併縮圖混合橫直時統一使用直式框架，橫式縮圖周圍不再填入底色。
- PDF 預覽支援點擊外圍黑色遮罩關閉，點擊預覽內容不會關閉視窗。

### Fixed

- 提高合併與拆分的 PDF 縮圖解析度至 360 像素寬，Retina 等高像素密度螢幕最高以 720 像素繪製，修正網格模式放大縮圖時文字與線條模糊。
- 補齊 PDF.js 預覽所需的 CMap、標準字型、WASM 解碼器與 ICC 資源，修正部分中文 PDF 預覽空白；開發與正式建置會自動複製與套件版本一致的資源，並支援 GitHub Pages 子路徑。
- 拆分 PDF 的自訂檔名在離開輸入欄位時自動排除重複名稱，以 `-1`、`-2` 等編號跳過已使用的檔名，並與實際下載名稱保持一致。

## [1.0.1] - 2026-09-29

### Added

- 工具選擇區的標題、說明與三張工具卡，以及工作區的左右面板加入依序淡入與輕微上移效果；切換工具時也會播放短暫進場動畫，直接開啟工具網址則立即顯示。
- 首頁 PDF 卡片旁的三個浮動標籤加入依序淡入效果，並配合減少動態效果偏好。
- 合併與拆分處理中可取消操作；拆分多份 PDF 時會顯示 ZIP 打包進度。

### Changed

- 略微放慢工具選擇區與工作區的淡入速度。

- 改善拆分頁面選取與輸出群組的計數效能，減少大量頁面時的重複查找。

## [1.0.0] - 2026-09-28

### Added

- 建立 Vite、React 與 TypeScript 的純前端 PDF 工作台，檔案在瀏覽器本機處理。
- 支援匯入多份 PDF，透過拖曳或鍵盤操作調整順序後合併下載；提供首頁縮圖、頁數及檔案大小資訊。
- 支援以頁面縮圖或頁碼範圍選取頁面，建立多個 PDF 輸出群組，並為各群組自訂輸出檔名。
- 支援每頁輸出一份 PDF；多份輸出會打包為 ZIP，單份輸出則直接下載 PDF。
- 加入檔案讀取與處理進度提示，以及無效或加密 PDF 的錯誤訊息。
- 加入 GitHub Pages 的建置與部署工作流程，依 Pages 回傳的路徑設定建置基底路徑。
- 加入頁碼範圍、合併頁面順序與拆分結果的自動化測試。
- 新增可拖曳、翻面的首頁 PDF 卡片與互動標題；卡片支援鍵盤操作，動畫會配合減少動態效果偏好。
- 新增首頁浮動提示與專用 SVG 圖示，呈現本機處理、合併及拆分流程。
- 新增 PDF 預覽視窗，可查看合併原檔、合併結果及拆分頁面，並以按鈕或方向鍵逐頁瀏覽。
- 新增「壓縮 PDF」工具，提供低、中、高三種壓縮強度；顯示壓縮前後大小與縮小比例，並可預覽及下載結果。
- 合併、拆分與壓縮工具新增獨立網址，支援直接開啟及在 GitHub Pages 重新整理頁面。
- 合併、拆分與壓縮工作區新增清除檔案操作。
- 檔案數量、頁數、大小與壓縮比例加入數字捲動動畫，並支援減少動態效果偏好。
- PDF 下載按鈕加入彩紙動畫。
- 拆分輸出的自訂檔名留空時使用預設名稱；同名檔案會自動加上數字後綴，並新增對應測試。

### Changed

- GitHub Pages 部署前會先執行測試與依賴安全稽核；只有 `.github/**`、`docs/**`、`README.md` 或 `src/tests/**` 檔案變更時不觸發部署。
- 改善手機與平板版面：調整頁首、工作區欄數、上傳區及觸控操作尺寸。
- 將應用程式依頁面外殼、合併與拆分功能、共用元件及 PDF 處理分層整理。
- 合併與拆分現在可處理能以空使用者密碼開啟、但受擁有者密碼限制的 PDF；檔案會在瀏覽器內解鎖，輸出不保留原加密設定。真正需要開啟密碼的 PDF 仍會提示無法處理。
- 重新設計首頁、工具選擇與工作區的深色介面，並調整不同螢幕尺寸的排版。
- 切換工具時重新建立工作區，先前匯入的檔案與設定不再保留；壓縮工具改為直接載入。
- 將合併、拆分與頁碼解析邏輯移至各功能目錄，整理共用檔案工具與 PDF 載入程式，並將測試集中至 `src/tests`。
- 更新套件名稱及儲存庫中繼資料為 `pdf-forge`。
- 合併檔案列改為點選縮圖或檔名開啟預覽，並以拖曳區與把手排序；移除上下移動按鈕。
- 上傳區改為整個區域皆可點選檔案，並加入會回應指標操作的點陣背景。
- 工具選擇改為連結至各工具網址；移除頁首的 `#top` 連結，舊的 `#top` 網址會回到首頁網址。
- 合併與壓縮工具共用新的輸出檔名欄位；聚焦時會選取現有名稱，留空後離開欄位則恢復預設名稱。
- 改善首頁卡片的觸控拖曳與垂直捲動，修正插畫在頁面捲動時的位置，並調整卡片及壓縮結果的版面。
